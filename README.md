\#kovbasniycod
Опис проекту
kovbasniycod — це експериментальна мова програмування, яка має:
-власний компілятор,
-стандартну бібліотеку для роботи з рядками, числами та колекціями,
-документацію для розробників,
-активне Community для обговорення та підтримки.

Мова створена для навчальних цілей та демонстрації базових принципів побудови мов програмування.

ІНСТРУКЦІЯ ЗІ ВСТАНОВЛЕННЯ
Клонувати репозиторій:

bash
git clone https://github.com/zaikamihaylo-hash/kovbasniycod.git
cd kovbasniycod
Запустити інсталяційний ua‑script:

bash
./install.ua
Переконатися, що компілятор доступний:

bash
kovbasniycod --version
Використання проекту
Створіть файл hello.kc:

kc
print("Hello, kovbasniycod!")
Скомпілюйте:

bash
kovbasniycod hello.kc -o hello
Запустіть:

bash
./hello
